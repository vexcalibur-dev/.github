# Support

Use the affected project's **Issues** page and choose the form that matches your need:

- **Question** for help understanding documented behavior.
- **Bug report** for a reproducible failure.
- **Feature request** for a new capability or compatibility change.

For command-line and Python questions, check the [Vexcalibur manual](https://vexcalibur-dev.github.io/vexcalibur/) first. The [GitHub Action](https://github.com/vexcalibur-dev/vexcalibur-action) and [CircleCI orb](https://github.com/vexcalibur-dev/vexcalibur-orb) keep their own usage and reference docs.

Public issues are public data. Use synthetic or already-public examples, redact logs, and remove credentials, private package names, internal URLs, and sensitive paths.

For a suspected vulnerability, do not use a public support form. Follow the [security policy](https://github.com/vexcalibur-dev/.github/security/policy) to report it privately.
