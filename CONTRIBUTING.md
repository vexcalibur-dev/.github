# Contributing

Thanks for helping improve Vexcalibur Dev projects.

## Development

- Keep changes focused and reviewable.
- Add or update tests for behavior changes.
- Run the repository's documented local checks before opening a pull request.
- Prefer small compatibility layers over ecosystem-specific assumptions in shared code.

## Pull Requests

Pull requests should include:

- A short description of the problem and solution.
- The commands used to verify the change.
- Notes about compatibility, migration, or security impact when relevant.
